## 0.3.1 - 2026-11-19

Commit `7a413635a708`; release record `pub:sha2-256:hoc2ng2qd3lkkcgsrlp7wbvv6pzlfanp5wk4y3tlt3la6sqikbrq`.

### Added
- pubsec signing-key restore [NAME ...] [--under DIR] [--dry-run]: each signing key pubrules.json declares that this machine lacks is read from its Bitwarden project (its value alone, with a token that may only read) and written to its declared path, readable by its owner alone; a key already there is never overwritten, a name the project does not hold once fails, and no key or token is printed

- pubdeploy 0.6.0 for the tests, which no longer has patch_pubsec; PubsecWorld's no-op override of it goes
